## Data

Item, price, trader, quest, hideout, craft and barter data come from the public Tarkov.dev API
(https://tarkov.dev, https://json.tarkov.dev). Data is fetched at runtime and cached locally; none is bundled.
The vector map drawings are Shebuka's tarkov-dev-svg-maps (https://github.com/the-hideout/tarkov-dev-svg-maps),
licensed CC BY-NC-SA 4.0 with a no-cheating-software clause; the satellite tiles are tarkov.dev's rendered maps
(authors as credited in maps.json: Shebuka, TarkovBOT.eu for Icebreaker, Tarkov.dev). The map shows the credit
("Map © Tarkov.dev / <author>") in its corner. Neither is bundled.
Map drawings (SVG) and map tiles come from https://assets.tarkov.dev and are downloaded when a map is first
opened, then cached under `%LOCALAPPDATA%\TarkovPriceOverlay\maps`. The map/quest feature reads the game's own
log files and the names of your screenshots; it never reads game memory. Optional TarkovTracker sync
(tarkovtracker.org / tarkovtracker.io) is read-only and only runs if you enter a token.
Escape from Tarkov is a trademark of Battlestate Games. This project is not affiliated with Battlestate Games
or Tarkov.dev.

## Test fixtures in the source repository

`tests/fixtures/live/*.json.gz` are recorded responses from the public Tarkov.dev JSON API (json.tarkov.dev,
23 Nov 2026), and `tests/TarkovOverlay.Maps.Tests/fixtures/*_sample.json` are trimmed samples of the same feeds.
They are used only by the unit tests and are not part of the program or the release downloads. The data comes from
Tarkov.dev (https://tarkov.dev); game names and data are Battlestate Games' (Escape from Tarkov). All other image
fixtures (`tests/fixtures/ocr`, `short`, `stack`, `trader`, `qdc`) are synthetic, generated by the scripts in `tools/`.

## Not used

No memory reading, injection, packet inspection or input automation. The price overlay only reads screen pixels
around the cursor. The 1.1 map reads Tarkov's text log files (map, raid start/end, quest messages) and screenshot
file names, and, only if you turn on the experimental exit-list reader, the top-right of the screen after you press O.
