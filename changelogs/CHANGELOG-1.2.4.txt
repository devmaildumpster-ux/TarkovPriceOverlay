Tarkov Price Overlay 1.2.4 (applies over 1.0.0 – 1.2.3, self-contained build)

INSTALL
1. Close Tarkov Price Overlay (if "Minimize to tray" is on: right-click the tray icon › Quit).
2. Copy every file and folder in this zip (including "licenses") into
   <your install folder>\TarkovPriceOverlay\self-contained
   and choose "Replace the files in the destination". Copy everything, not just the exe.
3. Start TarkovPriceOverlay.exe (overlay.log / smoke test says 1.2.4.0).
   Settings, tracked items, quest progress and map settings are kept.

FIXED: "POSSIBLE MATCH" WITH NO PRICE (e.g. AR-10 KAC QDC 7.62x51 Flash Suppressor Kit)
Why it happened: Tarkov wraps long names onto two lines. The OCR either lost the second line
("AR-10 KAC QDC 7.62x51 Flash") or misread a look-alike letter ("7.62x5l", "ODC"). The matcher then only had a
"possible" match, and a weaker possible match showed the name with no price at all.
- Look-alike letters (l/I/1, O/0/Q, S/5, B/8, Z/2, G/6, rn/m) count as the same letter when the result can only
  be one catalog item. Such reads now show the full card.
- The two name lines are also tried in the other order if the first order doesn't match.
- The first line of a two-line name (second line lost) gives a "Possible match" for the one item it starts.
- Every "Possible match" card shows Flea and Trader values, why the read wasn't exact, and up to two other items
  it might be, with prices. It's still marked "Possible match" — check before you sell.
- Safety: if the tooltip has two name lines but only the first was read and that line is itself an item name
  ("ELCAN SpecterDR 1x/4x scope" vs "… scope (FDE)"), it's a possible match, never a confident card.
- overlay.log: each lookup line now lists every OCR pass ("Windows@2× [line 1 / line 2] → kind (reason)") and the
  number of title lines found. If you still get a possible match, send those lines.
